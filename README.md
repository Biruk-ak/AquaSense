# AquaSense

Water Utility & Infrastructure Management Platform

## Applications

- **Consumer Portal** — account, bills, usage, service requests
- **Operations Dashboard** — field ops, leak detection, maintenance
- **Admin** — users, tariffs, districts, system configuration
- **API** — NestJS + TypeScript backend with PostgreSQL

## Features

- Smart Meter Readings
- Leak Detection
- Billing
- Maintenance
- Service Requests
- Infrastructure Mapping
- Notifications
- Analytics

## Stack

- TypeScript
- NestJS
- PostgreSQL (TypeORM)
- React portals
